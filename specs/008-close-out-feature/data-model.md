# Data Model: Close Out Feature

The workflow coordinates existing authority and evidence; it introduces no new persistent entity.

| Concept | Relevant information | Ownership |
| --- | --- | --- |
| Converged feature | Reviewed feature identity and convergence evidence | Consumer feature and operator |
| Completion operation | Separately approved lifecycle action or missing status | Project authority |
| Roadmap debrief and patch | Evidence and exact proposed verification change | Roadmap extension and operator |
| Curated context set | Durable sources selected for ingestion | Operator and Wiki extension |
| Commit-readiness disposition | Ready, flow-back, or blocked after lint and Git review | Operator |

The workflow must never collapse these concepts into one implicit acceptance event.
