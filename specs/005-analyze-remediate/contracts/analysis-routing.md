# Analysis Routing Contract

`feature_context` identifies the active artifact set. `integration` defaults to `codex`. `analysis_disposition` is provided at the human gate after read-only `speckit.analyze`.

| Choice | Route |
| --- | --- |
| `clean` | Stop with implementation available only on a separate operator instruction |
| `routine-spec-flowback` | Specify, plan, tasks, analyze |
| `routine-plan-flowback` | Plan, tasks, analyze |
| `routine-task-flowback` | Tasks, analyze |
| `constitutional-stop` | Stop for a separate approved amendment |
| `authority-or-scope-stop` | Stop for authority, material scope, or ambiguous recovery decision |
| `blocked` | Stop with blocker evidence |
| Unrecognized | Stop with manual controller fallback |

Routine routes are limited to the operator-issued controller scope. No route launches implementation or accepts the feature.
