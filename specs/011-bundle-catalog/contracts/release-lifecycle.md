# Release and Lifecycle Contract

The bundle pins `flow-roadmap` `0.2.1`, `flow-wiki` `2.0.1`, `flow-feedback` `0.2.1`, and eight reviewed workflow versions. Its version is `0.3.1`. A released catalog entry must match every pin, record each extension's source commit and required external tag, and contain a SHA-256 digest that matches the package bytes. Workflow entries must match reviewed source digests.

The local install and refresh tasks verify the release and exact tested Specify CLI before opening a temporary loopback catalog. Removal may delete bundle-owned components, but must retain unrelated independently installed components and the consumer-owned feedback journal. Native dispatch with a no-op Codex executable is routing evidence only.
