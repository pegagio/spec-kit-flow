# Synthetic Normalization Decisions — Open

Isolated synthetic clarification source variant. These decisions are deliberately open; no option is selected. Original artifacts and construction hashes are preserved separately as historical setup evidence.

- **AMB-ENCODING**: Which decoding and Unicode normalization policy applies?
- **AMB-EDGE**: Which characters should be removed at line edges?
- **AMB-BLANKS**: How should interior whitespace and logical blank lines, including trailing blank lines, be handled?
- **AMB-NEWLINES**: What should happen to CRLF and bare CR line endings?
- **AMB-FINAL-LF**: What output should empty input produce, and when should a final LF be added?
