# Synthetic Input and Error Decisions — Open

Isolated synthetic clarification source variant. These decisions are deliberately open; no option is selected. Original artifacts and construction hashes are preserved separately as historical setup evidence.

- **AMB-INPUT**: Accept exactly one file path, stdin, or both?
- **AMB-OUTPUT**: Should output go to stdout, update the input in place, or be written to another file?
- **AMB-ERRORS**: What exit status and output channels apply to missing paths, directories, and undecodable input?
- **AMB-SIZE**: Should the local utility impose an input size limit?
